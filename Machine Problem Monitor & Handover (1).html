Install Aplikasi di Handphone

Tampilan full-screen & ikon langsung di Home Screen

Browser Anda mendukung instalasi otomatis!

Pengguna Android (Chrome)

  1. Ketuk ikon menu ⋮ (tiga titik) di pojok kanan atas browser.
  2. Pilih "Add to Home screen" atau "Install app".
  3. Konfirmasi Install, ikon aplikasi akan muncul di layar utama HP.

Pengguna iPhone / iPad (Safari)

  1. Ketuk tombol Share di bagian bawah layar Safari.
  2. Geser ke bawah dan pilih "Add to Home Screen".
  3. Ketuk Add di pojok kanan atas.

Hubungkan ke Google Apps Script agar semua teknisi melihat data yang sama

Mode Lokal (Offline)

Cara Membuat Server Gratis di Google Sheets (3 Menit)

  1. Buka sheets.google.com dan buat Spreadsheet baru (beri nama misal: Monitoring Mesin).
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Hapus semua kode bawaan, lalu Paste kode di bawah ini dan klik ikon Save (💾).
  4. Klik Deploy → New deployment → Type: Web app → set Who has access: Anyone → klik Deploy, lalu salin Web app URL-nya ke kolom di atas.
